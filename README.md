# 路口火力（第一阶可玩版）

竖屏 9:16 的休闲自动射击小游戏。小队贴在画面下三分之一，左右两道同时入画：左道是奖励蓝门，右道是漫过来的卡通感染体。单指左右滑动整队，射击全自动。本目录既可在浏览器里直接玩，也带有微信小游戏项目壳，方便以后用微信开发者工具打开。

## 在浏览器里玩

需要已安装 [Node.js](https://nodejs.org/)（18 或更高）和 Python 3（用于本地静态服务，也可用任意静态服务器替代）。

```bash
cd lukou-huoli
npm install
npm run build
python3 -m http.server 4173 --bind 127.0.0.1
```

然后用浏览器打开：http://127.0.0.1:4173/

也可先构建再执行 `npm start`（构建后会启动同一端口的静态服务）。改了 `src/` 下的源码后，需要重新执行 `npm run build` 才会反映到 `game.js`。

桌面浏览器里，画布会按 9:16 居中显示，并留出边距，避免被浏览器工具栏裁切。手机请用竖屏访问同一地址。

没有 Node 时，只要目录里已有构建好的 `game.js`，也可以只启动静态服务：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

## 操作

- 手机：单指左右拖动，整队在左右两道之间移动。
- 桌面：按住鼠标左右拖动，或使用方向键 / A、D。
- 射击完全自动，子弹沿当前车道向前射出。没有开火键，也没有摇杆。
- 门是穿过即生效，不用把门上的数字打掉。两道同时出现门时必须二选一，走过就消失。
- 开局前三秒屏幕下方会提示「左右滑动 · 自动开火 · 穿蓝门加人」，滑动后立即消失。
- 右上角「音效 / 静音」可开关音效。没有音效也能完整游玩。

失败条件：人数归零。通关条件：坚持 90 秒并打完收束波。结算会显示击杀数、坚持时间和本局最高人数；最高击杀与最高人数会保存在本地。

## 第一阶做了什么

- 开局 1 人，默认手枪（伤害 1.0，约 4 发/秒，单体，永远保底）。
- 约第 6 秒左道必出蓝门「+3」，紧接着一扇冲锋枪武器门。
- 开局 2–7 秒右道出现 5 只游走体，1 人手枪即可打掉。
- 约 20–25 秒出一扇 ×2 蓝门；约 40 秒后出一扇红门「-3」（前 15 秒不会出红门）。
- 冲锋枪：单发伤害 0.7，约 12 发/秒，持续 15 秒，到期全队回退手枪。
- 敌人只有游走体（移速 1.0，生命 3）和冲刺体（移速 1.7，生命 2，体型更小，会突然加速）。碰撞都会掉 1 人；被碰到的人会闪白并进入短暂无敌，避免一次碰撞清掉整队。
- 人数硬顶 20。加人或 ×2 超过 20 时补到 20，超出部分转为 3 秒射速加成。
- HUD 含当前人数、武器图标（冲锋枪会显示剩余时间）和倒计时。开局、失败、通关界面齐全。第一局不插任何广告（广告只留了关闭的空壳）。
- 70 秒后不再出加人门，用已有人数和枪打完一小波游走体 + 冲刺体即可通关。本阶没有巨型 Boss，也没有厚皮体、霰弹或轻机枪。
- 角色、门和特效均为 Canvas 程序化绘制的卡通 Q 版。击中为黄白火花，击倒后碎成烟雾或色块粒子并在 0.3 秒内消失。界面文案使用「感染体 / 游走体 / 冲刺体」，不出现「丧尸」「杀戮」「血腥」等词。

隐私政策与适龄提示目前只是占位页，正式上架前再换成完整文案。

## 用微信开发者工具打开

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/minigame/dev/devtools/download.html)。
2. 选择「小游戏」，导入本目录（包含 `game.js`、`game.json`、`project.config.json` 的根目录）。
3. 把 `project.config.json` 里的 `"appid": "touristappid"` 换成你的小游戏 AppID。也可以在开发者工具的项目设置里填写。还没有 AppID 时，可用测试号 / 游客模式先预览。
4. 编译模式为「小游戏」，设备方向已在 `game.json` 中设为竖屏 `portrait`。
5. 正式上传前请先执行 `npm run build`，确保 `game.js` 是最新的。`src/`、`tests/`、`node_modules/`、`index.html` 等已写进 `packOptions.ignore`，不会打进上传包。主包是单文件脚本 + 配置，体积远小于 4MB。

浏览器版入口是 `index.html`；微信小游戏入口是根目录的 `game.js`。两边共用同一套构建产物，平台差异（画布、触摸、本地存储、音频）在 `src/platform.ts` 里做了适配。

## 开发与验收

```bash
npm install
npm run build    # 把 src/ 打包成根目录 game.js
npm test              # 逻辑与时间轴自动验收
npm run test:browser  # 需本机有 Chrome，并先启动上面的本地预览；依赖 puppeteer-core
```

时间轴和数值以同目录的 `phase1-spec.md` 为准。

## 项目结构

```
lukou-huoli/
  index.html              浏览器入口

  project.config.json     微信项目配置（appid 在此填写）
  src/                    TypeScript 源码
  tests/                  自动验收
  phase1-spec.md          第一阶规格
```
