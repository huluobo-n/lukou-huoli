# 路口火力（第一阶可玩版）

竖屏 9:16 的休闲自动射击小游戏。小队贴在画面下三分之一，左右两道同时入画：左道是奖励蓝门，右道是漫过来的卡通感染体。单指左右滑动整队，射击全自动。本目录既可在浏览器里直接玩，也带有微信小游戏项目壳，方便以后用微信开发者工具打开。

## 在浏览器里玩

需要已安装 [Node.js](https://nodejs.org/)（18 或更高）和 Python 3（用于本地静态服务，也可用任意静态服务器替代）。

```bash
cd lukou-huoli
npm install
npm run build
python3 -m http.server 4173 --bind 127.0.0.1
```

然后用浏览器打开：http://127.0.0.1:4173/

也可先构建再执行 `npm start`（构建后会启动同一端口的静态服务）。改了 `src/` 下的源码后，需要重新执行 `npm run build` 才会反映到 `game.js`。

桌面浏览器里，画布会按 9:16 居中显示，并留出边距，避免被浏览器工具栏裁切。手机请用竖屏访问同一地址。

没有 Node 时，只要目录里已有构建好的 `game.js`，也可以只启动静态服务：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

## 操作

- 手机：单指左右拖动，整队在左右两道之间移动。
- 桌面：按住鼠标左右拖动，或使用方向键 / A、D。
- 射击完全自动，每个小兵各走一条弹道向前射出。没有开火键，也没有摇杆。
- 门穿过即生效。两道同时出现门时必须二选一。也可以开枪给加减门充能：每打中一发，门上数字 +1，红门 -N 能打成蓝门 +N（有上限）。倍增门和武器门打不改变数值，但会吃掉子弹。
- 开局前三秒屏幕下方会提示「左右滑动 · 自动开火 · 穿蓝门加人」，滑动后立即消失。
- 右上角「音效 / 静音」可开关音效。没有音效也能完整游玩。

对局为无尽生存：人数归零即结束，没有 90 秒通关。结算会突出坚持时间，并显示击杀数和本局最高人数；最长坚持、最高击杀与最高人数会保存在本地。

## 第一阶做了什么

- 开局 1 人，默认手枪（伤害 1.0，约 4 发/秒，单体，永远保底）。
- 约第 6 秒左道必出蓝门「+3」，紧接着一扇冲锋枪武器门。
- 开局 2–7 秒右道出现 5 只游走体，1 人手枪即可打掉。
- 约 20–25 秒出一扇 ×2 蓝门；约 40 秒后出一扇红门「-3」（前 15 秒不会出红门）。
- 冲锋枪：单发伤害 0.7，约 12 发/秒，持续 15 秒。中段起还会出现「重击」（单发 3.4，约 2.4 发/秒，持续 15 秒，能打穿盾兵减伤）。到期回退手枪；满编 20 人时到期会补一小段护盾，并陆续有下一扇武器门可选。
- 教学段敌人是游走体（移速 1.0，生命 3）和冲刺体（移速 1.7，生命 2，会突然加速）。教学结束后更早出现跳跃体（约 16 秒，腾空时打不中）、盾兵（约 28 秒，承伤减半）、爆裂体（约 38 秒，碰队掉 3 人）和分裂体（约 50 秒，死后拆成 2 个小子）。被碰到的人会闪白并进入短暂无敌。
- 约 12 秒起，右道中距会出现金色增幅门：子弹穿过后伤害 ×2，已经走到门前的感染体承伤 ×0.5。金门会在一段时间后消失，中后段再短暂重开并换位置；重开时会先抽稀并暂停右列。「躲开右道！」和「右道×2！快切」不会叠在同一窗口；躲开右道要等「金门关闭！」横幅完全结束，不能只等门消失。关闭后右道危险会回来，适合短切去吃 ×2 或清列。
- 约 28 秒起会有红预警，横幅会写清「躲开左道！」或「躲开右道！」；换道可免伤，留下则掉 7 人。之后间隔逐渐收到约 7 秒一次。不要一直蹲左道。
- 左道偶尔出现人质笼，开枪打开可加人（+3），笼子上会标明「救出」和血量；没打开就抵达只是错过奖励。右道偶尔出现油桶，开枪引爆可清附近感染体，没引爆就碰到会掉 2 人。若开局错过第一扇加人门，约 10 秒会在当前车道补一扇近距 +2，避免空死，但前 10 秒本身不会变简单。
- 约 36 秒起会有「左道来袭！」：左道被橙色标出后，会有一小队感染体从左道冲下来。第一次来袭后会短暂安静重整，随后出现具名事件「左右夹击！」（左右同时放怪）。约 60 秒街道会切到夜路口（分隔带、沿街建筑和巷口都会换，不只是天色变暗），入夜时会刷新重击并补护盾；若当时正有「躲开左道！」，会等这次换道完成再打出入夜横幅。入夜后到约 2:30 前会放缓出怪和血量涨幅，事件也再错开一些，方便打到「守住中道」。之后「巷口来袭！」会写明方位，多从单侧插进，躲开后不会立刻再叠巷口，更不会马上左右同时插进。入夜后重击会拉长到硬段结束，冲锋枪门在此期间不会把它换掉。约 2 分 30 秒再进入岔路口，短暂要求「守住中道！」，奖励在中间车道；结束后会先留出空档，再打出看得见的「雨夜推进！」横幅，不会在几秒内被后续事件清掉。
- 人数硬顶 20。加人或 ×2 超过 20 时补到 20，超出部分转为 3 秒射速加成，并加上约 5.5 秒护盾（够完成一次切道）。教学结束后（约 16 秒），满编时门会写成「护盾」，不满编只小幅补人（约 +1，人很少时 +2），白天也不会再出现一扇 +15 补满，更不会护盾和 +15 并排。开局约 10 秒教学、容错 +2 和满编前的左道奖励仍保持友好。
- 教学结束后，感染体生命会随存活时间变厚（约每秒 +2%；入夜到岔路口前涨得较慢，过了 2:30 再加快）。HUD 含当前人数、武器、已坚持时间和本局击杀。开局、结算界面齐全。第一局不插任何广告（广告只留了关闭的空壳）。
- 70 秒后脚本段结束，仍会持续出怪并补武器门和护盾门；无尽段的门、事件时间和巷口方位会随对局变化，第二局不是同一条钟点表。入夜后一直蹲左边也不再能轻松把人数补回 20。本阶没有巨型 Boss。
- 角色、门、房屋和界面使用 Q 版粘土风贴图（`assets/`），击中为黄白星星火花，击倒后碎成柔和色块并在 0.3 秒内消失。界面文案使用「感染体 / 游走体 / 冲刺体」，不出现「丧尸」「杀戮」「血腥」等词。

开屏底部可查看隐私与适龄说明：先是精简版，再分别进入可滚动的《隐私政策》和《适龄提示》完整页。

## 用微信开发者工具打开

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/minigame/dev/devtools/download.html)。
2. 选择「小游戏」，导入本目录（包含 `game.js`、`game.json`、`project.config.json` 的根目录）。
3. 把 `project.config.json` 里的 `"appid": "touristappid"` 换成你的小游戏 AppID。也可以在开发者工具的项目设置里填写。还没有 AppID 时，可用测试号 / 游客模式先预览。
4. 编译模式为「小游戏」，设备方向已在 `game.json` 中设为竖屏 `portrait`。
5. 正式上传前请先执行 `npm run build`，确保 `game.js` 是最新的。`src/`、`tests/`、`node_modules/`、`index.html` 等已写进 `packOptions.ignore`，不会打进上传包。主包为 `game.js`、配置和 `assets/` 贴图，总体积远小于 4MB。

浏览器版入口是 `index.html`；微信小游戏入口是根目录的 `game.js`。两边共用同一套构建产物，平台差异（画布、触摸、本地存储、音频）在 `src/platform.ts` 里做了适配。

## 开发与验收

```bash
npm install
npm run build    # 把 src/ 打包成根目录 game.js
npm test              # 逻辑与时间轴自动验收
npm run test:browser  # 需本机有 Chrome，并先启动上面的本地预览；依赖 puppeteer-core
```

时间轴和数值以同目录的 `phase1-spec.md` 为准。

## 项目结构

```
lukou-huoli/
  index.html              浏览器入口
  game.js                 构建产物（浏览器与微信共用）
  game.json               微信小游戏配置（竖屏）
  project.config.json     微信项目配置（appid 在此填写）
  src/                    TypeScript 源码
  tests/                  自动验收
  assets/                 Q 版角色、门、场景与 HUD 贴图
  phase1-spec.md          第一阶规格
```
